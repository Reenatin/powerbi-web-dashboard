# Getting Started

1. Install Node.js 20+ and npm.
2. Run `npm install`.
3. Copy `.env.example` to `.env`.
4. Configure Microsoft Entra ID and Power BI IDs.
5. Run `npm run doctor`.
6. Start with `npm run dev`.
7. Use the UI button **Test connection**.
8. Add one card to `config/dashboard.json` using a real measure.
9. Add filters and charts incrementally.

Start small: one working measure is more useful than configuring an entire dashboard before validating access.
